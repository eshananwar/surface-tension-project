# Our Science Project — Surface Tension

A responsive, animation-rich science exhibition introduction website for Ideal English School, Sultan Bathery.

## Files
All files are intentionally kept directly inside this one folder:
- `index.html` — page content
- `style.css` — layout, responsive design, 3D-style CSS animations
- `script.js` — scroll reveals, progress indicator, mobile navigation and molecule visuals
- `project-logo.svg` — custom project logo and browser favicon
- `school-logo.png` — add your school's logo using this exact filename

## Add your school logo
1. Get a clear image of the official Ideal English School logo.
2. Copy it directly into this folder (beside `index.html`).
3. Rename it exactly to `school-logo.png`.
4. The website displays it inside a light rounded-square frame using `object-fit: contain`, so the complete logo remains visible and fits the shape without being stretched or cropped.

If your logo is JPG, convert it to PNG first, or change the image filename in `index.html` to match your file.

## Preview
Double-click `index.html` to open it in a browser. Internet is only needed to load the optional Google Fonts; the rest of the website works locally.

## Publish with GitHub Desktop
1. Open GitHub Desktop and sign in.
2. Choose **File → Add local repository**.
3. Select this `0` folder. If GitHub Desktop says it is not a repository, choose the option to create a repository here.
4. Commit the files, then publish to the GitHub repository you created.
5. On GitHub, open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
7. Wait for the Pages URL to appear. Open it and test on a phone.

## Notes
- The molecule illustration is a simplified educational model, not a scale diagram.
- The 3D droplet and experiment visuals are CSS illustrations. Use your real experiment photos later if you want to replace them.
- The website is an introduction to your project, not a quiz or judge question bank.
